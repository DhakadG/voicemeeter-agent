1. INTRODUCTION
================================================================
VoicemeeterRemote API is based on a standard DLL providing all functions to control
Voicemeeter Audio Engine by any user application programmed in any language.
Supports up to 4 client applications simultaneously.

================================================================
2. INSTALLATION / PACKAGE / LICENSING
================================================================

INSTALLATION:
Voicemeeter must be installed and running.
VoicemeeterRemote.dll must be linked to the user application.

PACKAGE CONTENT:
- VoicemeeterRemote.h (C Header file)
- VoicemeeterRemoteAPI.pdf (this doc)
- ReadMe.txt

================================================================
3. API GENERAL POLICY
================================================================
- All functions use __stdcall convention, return 32-bit integer.
- Return > 0: result value. Return < 0: error code. Return 0: OK/ZERO.
- All functions are thread-safe and non-blocking (asynchronous) unless noted.
- Supported data types: long (32-bit int), char* (ANSI), WCHAR*/unsigned short* (Unicode), float (32-bit).

4. LINK TO VOICEMEETER DLL
================================================================
Always link to the DLL installed with current Voicemeeter for compatibility.

// Get install folder from registry
if (RegistryGetVoicemeeterFolder(szDllName) == FALSE) return -100;

// Select 32 or 64-bit DLL
if (sizeof(void*) == 8) strcat(szDllName,"\\VoicemeeterRemote64.dll");
else strcat(szDllName,"\\VoicemeeterRemote.dll");

G_H_Module = LoadLibrary(szDllName);
iVMR.VBVMR_Login  = (T_VBVMR_Login)GetProcAddress(G_H_Module,"VBVMR_Login");
iVMR.VBVMR_Logout = (T_VBVMR_Logout)GetProcAddress(G_H_Module,"VBVMR_Logout");
// etc...

Function: BOOL __cdecl RegistryGetVoicemeeterFolder(char * szDir)

================================================================
5. LOGIN / LOGOUT
================================================================
Uses client/server protocol. Login = register with remote service.
- Login/Logout called ONCE at start/end of application.
- Login works regardless of whether Voicemeeter is running.
- Voicemeeter can be restarted during an active login session.

rep = iVMR.VBVMR_Login();
if (rep < 0) { /* error */ }
if (rep == 1) {
    // Voicemeeter not running, launch it:
    iVMR.VBVMR_RunVoicemeeter(2);
    Sleep(1000);
}

// Initialize parameters after login:
ComError = iVMR.VBVMR_IsParametersDirty();
ComError = iVMR.VBVMR_MacroButton_IsDirty(); // MacroButtons only

// Detect connection/disconnection via ComError >= 0 (connected) or < 0 (disconnected)

IMPORTANT: Call VBVMR_Logout() once at program end.

8. GET/SET PARAMETERS & SYNCHRONIZATION
================================================================

GET/SET:

SYNCHRONIZATION:
long __stdcall VBVMR_IsParametersDirty(void);
Returns 1 if parameters changed. Call in timer/polling loop.

fDisplayParam = iVMR.VBVMR_IsParametersDirty();
if (fDisplayParam != 0) UpdateVisibleParameter(...);

MACROBUTTONS SYNC:
long __stdcall VBVMR_MacroButton_IsDirty(void);
Returns 1 if any button state changed.

REAL TIME LEVEL METER:
// Example: 22 input levels for Voicemeeter Banana
for (vi=0; vi<22; vi++) {
    NormalLevel = 0.0f;
    iVMR.VBVMR_GetLevel(0, vi, &NormalLevel);
    DisplayLevel(dc, NormalLevel);
}

REAL TIME MIDI:
Call VBVMR_GetMidiMessage() in sync loop to get MIDI input from device
selected in Voicemeeter MIDI Mapping Dialog.

11. VB-AUDIO CALLBACK
================================================================

FUNCTIONS:
VBVMR_AudioCallbackRegister();
VBVMR_AudioCallbackStart();
VBVMR_AudioCallbackStop();
VBVMR_AudioCallbackUnregister();

Up to 3 callbacks from 3 different applications.

CALLBACK TYPES:
1. Input Insert (Pre-Strip) - process/record inputs before Voicemeeter processing
2. Output Insert (Pre-Master BUS) - process outputs before master section
3. Main (all I/O) - receive all I/O, record or replace output signal

Called in order 1 → 2 → 3.

AUDIO BUFFER STRUCTURE:
typedef struct tagVBVMR_AUDIOBUFFER {
    long  audiobuffer_sr;       // Sampling Rate
    long  audiobuffer_nbs;      // samples per frame
    long  audiobuffer_nbi;      // number of inputs
    long  audiobuffer_nbo;      // number of outputs
    float* audiobuffer_r[128];  // input buffers
    float* audiobuffer_w[128];  // output buffers
} VBVMR_T_AUDIOBUFFER;

CHANNEL ORGANIZATION - INPUT CALLBACK:
Voicemeeter Standard:
  Strip#1(0,2ch) | Strip#2(2,2ch) | Virtual(4,8ch)

Voicemeeter Banana:
  Strip#1(0,2) | Strip#2(2,2) | Strip#3(4,2) | Virtual(6,8) | VirtualAUX(14,8)

Voicemeeter Potato:
  Strip#1(0,2)|Strip#2(2,2)|Strip#3(4,2)|Strip#4(6,2)|Strip#5(8,2)|Virtual(10,8)|VirtualAUX(18,8)|VAIO3(26,8)

CHANNEL ORGANIZATION - OUTPUT CALLBACK:
Voicemeeter Standard:
  BUS A(0,8) | BUS B(8,8)

Voicemeeter Banana:
  BUS A1(0,8) | BUS A2(8,8) | BUS A3(16,8) | BUS B1(24,8) | BUS B2(32,8)

Voicemeeter Potato:
  A1(0,8)|A2(8,8)|A3(16,8)|A4(24,8)|A5(32,8)|B1(40,8)|B2(48,8)|B3(56,8)

MAIN CALLBACK CHANNEL ORGANIZATION:
Voicemeeter Banana (Inputs):
  In#1(0,2)|In#2(2,2)|In#3(4,2)|V1(6,8)|V2(14,8)|A1(22,8)|A2(30,8)|A3(38,8)|B1(46,8)|B2(54,8)

Voicemeeter Potato (Inputs):
  In#1(0,2)|In#2(2,2)|In#3(4,2)|In#4(6,2)|In#5(8,2)
  |V1(10,8)|V2(18,8)|V3(26,8)
  |A1(34,8)|A2(42,8)|A3(50,8)|A4(58,8)|A5(66,8)
  |B1(74,8)|B2(82,8)|B3(90,8)
Output channels: same as Output Callback.

CALLBACK COMMANDS:
VBVMR_CBCOMMAND_STARTING  - Initialize DSP objects (first call)
VBVMR_CBCOMMAND_ENDING    - Release structures (last call)
VBVMR_CBCOMMAND_CHANGE    - Samplerate or buffer size changed
VBVMR_CBCOMMAND_BUFFER_IN   - Process Input INSERT buffer
VBVMR_CBCOMMAND_BUFFER_OUT  - Process Output INSERT buffer
VBVMR_CBCOMMAND_BUFFER_MAIN - Process all I/O (Banana: 22in+40out; Potato: 34in+64out)

CALLBACK SIGNATURE:
long __stdcall PROCESSING_MyCallback(void* lpUser, long nCommand, void* lpData, long nnn);
